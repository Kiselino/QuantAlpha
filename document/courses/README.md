# 官方课程与学习素材（courses）

> 本目录收录 WorldQuant BRAIN **官方公开课《零基础学量化》（AI 版）课程笔记**与**官方教程/作业题提取件**，
> 供任何人备考 BRAIN 研究能力测试/面试与学习平台知识使用（bootcamp 教材源）。
> 全部为官方公开材料的知识笔记/摘录，无个人账号/分数/身份信息、无可提交 alpha 表达式细节。

## 合规边界

- 题源仅限官方公开材料（官方公开课、help center、/learn 教程、官方课程作业帖）
- **严禁收集/整理/传播面试真题、答案、题库、面经**——本目录不含此类内容；使用本目录出题练习时同样不得引入
- 课程笔记中时间敏感信息保留口径日期标注（平台政策会变化，如 2026-06 起新增面试环节）

## 答疑内容去向说明

课程答疑（Q&A）文件不单独保留——其中知识增量已归并到既有参考文档（去重后补充）：
- 顾问考核/工作性质/IQC 一次性/质量分机制 → `document/reference/rules.md`
- 回测效率预期/过拟合前提/加噪音警告 → `document/reference/pitfalls.md`
- coverage 双口径 → `document/reference/fields.md`
- 准入限制补充（个人炒股） → `document/flows/access.md`
- 课程渠道（公众号/论文推送） → `document/flows/learning.md`
- 提交时机策略/平台机制杂项/学习路径论 → `document/reference/community.md`
