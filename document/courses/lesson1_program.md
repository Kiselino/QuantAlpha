## 收入结构（两池机制——解开 60 vs 120 矛盾）

- 每日津贴 Base Payment：**1-60 USD**（提交 alpha）
- 开通 "Output Alpha" 权限后竞争**另一个 1-60 USD 池** → 每日最高 **120 USD**（bilinote 版"1-120"实为双池合计；仓库 rules.md 的 1-60 只记了单池）
- 季度奖 Quarterly Payment：季度内 ≥20 天提交即可竞争，100-25000 USD
- 推荐奖 Referral：成功推荐他人成为顾问且对方 10 个自然日内有提交 → 100 USD
- 各收入可同时获取

## 关键机制补充（BibiGPT 版新增）

- **OS 测试机制**：平台截断约 2023 年之后的数据用于样本外测试（规避回测期好但实盘失效的 alpha）——对市场的敬畏
- Alpha 评级基于多项指标综合（Sharpe/Turnover/Return…），无单一关键指标
- 提交的 alpha 不会被公司直接使用，目的 = 学习与积累
- 官方学习渠道：**公众号"Brain 智能助手"**（作业 3 阅读材料出处）
- 量化基金架构：数据组 → 研究组（Alpha Research，顾问角色在此）→ 组合管理 → 策略 → 执行
- 顾问核心两件事：产生想法（动量/反转）+ 用表达式语言写出来

## 要点摘录（按备考价值抽取）

### 公司/项目背景（M1）
- WorldQuant 2007 年成立，27 办公室 / 13+ 国家 / 1000+ 员工；BRAIN 是外部研究者提交 alpha 的平台
- 兼职顾问计划 = 法律意义的兼职（劳务关系），需依法纳税；背调严格，资料须与身份证/银行卡一致
- **金融行业从业者无法通过背调**（利益冲突），应主动退出
- 顾问门槛：1 万积分；单个 alpha 通常 1000-2000 分；每日提交上限 2000 分（最快 5 天攒够）
- 收入结构：基础津贴 1-120 USD（⚠️ 与仓库 rules.md 记录的 1-60 USD/天不一致，待核实——可能讲师口径或文档过时）+ 季度奖 100-25000 USD + 推荐 100 USD

### Knowledge Quiz（新增信息，素材里此前没有）
- 成为顾问前必须通过一次"知识问答"审核（即使不参加培训）
- 两次答题机会；目的：确保具备基础概念认知，防止不懂关键术语者获得提交权限
- 讲师原话："会在未来的各种问卷里问这些知识，保证这些难点都不懂的同学不能成为顾问"

### IQC 与 Genius
- IQC：新手只与同组竞争（新手保护）；被淘汰不影响后续资格；报名在 Competition → Challenge → IQC
- Genius Program 四级别：GRANDMASTER/Master/Expert/Gold，保底奖金（GRANDMASTER 8000 USD、Master 2000 USD）

### Alpha 基础概念（M2）
- Alpha = 预测股票未来收益的数学公式；有效 = 计算值与未来回报强相关
- 两类核心策略：动量（好者恒好）/ 反转（均值回归）——矛盾并存
- 平台数据字段 = 表格（横轴时间、纵轴股票）；新手只允许横/纵两个维度操作，不允许"斜向"交叉（A 公司今日价 - B 公司昨日价）；允许嵌套（先横向排序再纵向判断）
- 案例：单一"负债"因子太简单无效 → 改为资产负债率（比率化思路）；"Self Correlation Too High"= 与已提交 alpha 高度重合，顾问后还要与全平台比独特性
- AI 辅助：可让 DeepSeek 等生成变体，但 **AI 会编造不存在的字段** → 报错 Unknown Variable 时回 Data 搜索页核实替换

### 回测与提交（M4 入门）
- Simulation 页面；新手保持默认 Region/Universe，Test Split 改 0 简化
- PnL 图 = 累计损益；OS 数据提交后不可见（防过拟合）；评测基于 IS
- 未通过 IS Testing 不能提交；无单一关键指标，综合看待
- 提交成功后在 Submitted 菜单查看；截图须含时间戳（作业证据）

### 作业（Day1，官方 Course1 作业对应）
1. AI 帮助至少提交 1 个成功 alpha + 截图（含时间戳）
2. 学习回测页关键术语（小蓝点标注）+ Settings，向 AI 问概念（如 Sharpe/Turnover），对 AI 回答点赞/点踩并截图
3. （最重要）阅读公众号解释文章 + 完成一道数学题（理解"表达式如何生成曲线"）——5 股票权重计算类
