## 1. 作业讲评：从数据集 vs 从论文获取模板（两条互补路径）

- 上节作业 = 从数据集出发（AI 给 ≥3 模板）；本节 = **从论文出发**
- 平台入口：小铃铛推送 → research paper（同事精选）→ Learn → "research paper for users"——论文附**摘要 + 可用数据字段清单** → 字段直接 Data 页搜（研究员的提示本身就能定位 alpha）
- 论文工作流（讲师示范，AI 时代研究员的完整流程）：
  1. 找原文（平台打不开可百度搜）；46 页论文不硬读
  2. 全部模板粘贴给 AI → "总结成易读 MD"（可写到本地目录留痕给未来 AI 读）
  3. **一个聊天框只干一件事**；新建对话（防上下文污染）→ "阅读该文件，选取 5 个最相关模板"
  4. 展开模板 → 回测
  5. **但先要理解论文**（用翻译工具如"超能文献"，免费）：不懂论文就展开 = 找到也不会改、不知道好在哪里；AI 会骗人，理解后才能识别（炒菜不洗菜的比喻）
- 数据→模板路径可不用深理解（原始数据 AI 连点成线）；**论文→模板路径必须理解论文**（写出的 alpha 更长更有逻辑、独特性更高）
- 作业提交 134+ 条评论 = 300+ 模板可参考

## 2. decay 公式与参数纪律（本课补的第一个知识点）

- decay 定义：把过去 N 天交易信号按时间加权平滑
- **公式（带例题）**：decay=N 时，新权重 = Σ(今天权重×N + 昨天×(N−1) + … + 最旧×1) / (N+(N−1)+…+1)；例 N=3 → 分母 3+2+1=6，分子 = 今×3/6 + 昨×2/6 + 前×1/6
- **参数纪律（关键提醒）**：decay 窗口不能超过表达式内的时间窗口——表达式只用过去 5 天信息却设 decay=20，等于把 idea 里本没有的信息搂进来 → 不合理
- 参数设置必须与表达式表达的意思匹配（不是随便调的旋钮）

## 3. vector data（本课补的第二个知识点，讲师明示"知识问答中的一道题"）

- **matrix data（二维）= 横轴时间 × 纵轴股票，一天一个值**（如 close）
- **vector data（三维）= 一天可有多个值**（如 news：一条条新闻 + 各自市场反应）；也可能一天无值（无人关注）
- **必须用 vector operator 压缩成二维才能写表达式**；不用会报错 "you take too much resources"
- ⚠️ vector≠数学向量、matrix≠数学矩阵（平台命名与数学无关，别混淆）
- **压缩 = 信息提纯而非损失**：例 = 新闻情绪当天的标准差大 → 情绪分歧（地缘新闻坐过山车）——可捕捉新信号；vector_true = 取当天最后一个值（收盘前）
- 用法建议：alpha 相关性偏高时可尝试 VECTOR 类数据（低相关来源）
- 模板代码细节：matrix 模板要限定 matrix data（否则套 vector operator 会报错）

## 4. 过拟合（方法论核心起点）

- **回测数量是谈过拟合的前提**：一天回测 500 次没资格谈；代码批量回测者要特别小心
- 危险行为：不断调参追样本内加分（1000→1100→1111 分）——样本内越 fit，样本外越降
- **样本外表现间接可见**：① 提交前 IS Testing 预留段（故意留一段不看，提交前验证斜率保持）② 提交后看钱——**每天低于 1.5 美元基本确定样本外不咋地**

## 5. 组合效应与质量分（收入核心逻辑，必考向）

- **好 alpha 组合 1+1>2**；差 alpha 1+1<2（越交分越低——"越交分数越低"的解释）
- 提交越多 → 单 alpha 边际增量越小、分数越失真 → 前期分数最有意义，后期无法判断是真实增益还是随机波动
- **质量分机制**：默认 0.5（排名分）；**只有拿到钱的 alpha 才计入质量分**；质量分 0.3 → 交世界最强 alpha 也只有 ~1 美元（"每天一杯瑞幸咖啡"）；0.9 → 十几美元；同一个 alpha 不同人交价值不同
- 泥潭效应：组合里已有差 alpha 时，交 1 个差的约需 10 个好的才能扭转
- 中国区月度 300+ 顾问质量分 >0.8（活跃 1000+ 人）——好好干比例不低

## 6. 质量四原则（提交前可让 AI 按此评估）

1. **Robustness（稳健）**：稳定向上 > 暴涨暴跌（赚得多也能亏得多；稳才能上杠杆；肉眼看 PnL 曲线）
2. **Uniqueness（独特）**：不是前无古人，而是**真的在捕捉某个确切的东西**（错误定价/统计特征）——表达式有理、可读；**一锅乱炖/混信号是大忌**（新手千万别混信号；多因子不是这么来的）
3. **Value Add（组合增益）**：汝之蜜糖彼之砒霜——已有组合太多基本面就补别的数据集；组合视角评估
4. **Consistency（一致性）**：稳定（与 robustness 同源，底线要求）
- 第六感法则：觉得不靠谱就是不靠谱；当你想问别人"这 alpha 能不能交"时，答案已是否定
- **不要在一个 alpha 上钻牛角尖**：改多了 → 过拟合 + 与已有 alpha 高相关；放一放，有系统性新想法再回来
- 好 alpha 的细节示范：好模板会先 ts_fill 填充（但新闻数据时效性强不该填！按数据集判断）、消除极值再回测

## 7. 参赛与代码建议

- 多尝试不同数据集/universe（同一 alpha 换 universe 可能出新 alpha）；be open minded（AI 时代没学过也能干）
- IQC 组队必须**同校/校友**——验证学校身份时不符会被取消资格；不要乱写学校
- 代码架构：**表达式生成程序与回测程序分离**（写表达式存 CSV/数据库 ↔ 专注读取回测）→ 稳健 + 可插队（新表达式插最上面，回测机器人优先抓）
- 顾问社区有热心顾问分享工具；顾问有专门论坛
- 资源渠道：公众号"Brain 智能助手"（新手村社群有录播）、超能文献（论文翻译，免费）、Trae/豆包等 AI 代码工具
