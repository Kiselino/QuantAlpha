## 1. 作业讲评：如何用 ts_std_dev 测数据更新频率（Course2 作业 3 的标准答案逻辑）

- **coverage 是均值**：平台上显示的 coverage 是平均覆盖股票数，若字段只有一两天有值，平均下来会很少 → long count 少 ≠ 数据质量差
- **定性先行**：读字段描述（如 anl4_cff_flag = 分析师对某公司融资活动现金流 forecast type 的修正/补充预测）→ 知道类别（分析师类）
- **定量探测**（作业要求）：neutralization 必须关掉再算——**出现负数说明 neutralization 没关**（要么 1 要么 0 的 flag 字段不该有负值）
- **ts_std_dev 测更新频率的数学逻辑**（讲师逐步推导，必考逻辑）：
  1. 某股票连续 5 天值全为 1 → 该数列标准差 = 0（无波动）→ 至少周度更新（日度数据该变就变）
  2. 标准差 ≠ 0 ⟺ 这段时间内值有变动
  3. 把窗口参数从 66→200→400（1 年）→ long count 不再涨（TOP3000 中只有 1000+ 只）→ 5 年窗口（参数 1000）→ 接近 3000 只
  4. 结论：**该字段更新周期不固定**——分析师不跟了（退市/跳槽/公司没人关注）
- **关键认知**（讲师升华）：数据不波动 ≠ 不携带信息（身高 18 岁后不长了 → "已成年"信息）；不要先入为主认为数据必须频繁变化；**用数据字段前必须懂它的定性+定量**——否则写出 30% 换手的 alpha 却不知数据根本不这样变，质量必然差
- 标准差作为"统计探针"是数学当工具的思维示范

## 2. trade_when 算子详解（上节课遗留，含逐步计算例题）

- 三参数：**第三参数 = 平仓条件**（成立 → 清仓）；**第二参数 = 开仓/更新条件**（第三不成立时判断，成立 → 更新 alpha 值）；**第一参数 = alpha 值**
- 例题逻辑（A 股票，close 判断）：close<2 平仓 → 否则 close>10 则更新为当日 alpha 值 → 否则沿用上一次的值；**无旧值则输出 none**
- 含义：非线性变换——把连续 alpha 变成带开/平仓条件的择时信号；B/C 股票一直 none 是因为条件从未触发（感受非线性）

## 3. 中性化 Neutralization（本课核心，讲师打包票知识问卷必考）

- **两种中性化**：风险中性化（课本概念，顾问后才可用）vs **多空中性化**（本课内容，新手可用）
- 多空中性化本质：**一半钱做多、一半钱做空**（是"钱"不是"股票数量"）；净头寸 = 0
- 市场下跌也有空头收益、上涨有多头收益；操作不当也会两头亏；几千只股票符合大数定律
- **数学公式**：新 alpha 值 = 原值 − 全体均值 → 求和必为 0（数轴平移）；极端值会拉偏均值 → 改变多空方向与数量
- **权重计算流程**（平台内部，第一课作业文章的延伸）：
  1. 中性化后值（正负相加 = 0）
  2. 全部取绝对值求和
  3. 每个值 ÷ 绝对值总和 = 该股票权重（如 100 元 × −50% = 做空 50 元）
- **示范观察**：neutralization=None 时 long count=3（数正数）；打开后 long count 变多、做空仓位 50% → 平台报错提交不了——**中性化会改变多空方向与分布**
- 设置选项：Market / Industry / Subindustry（分组概念由此产生）；分组内部各自净零；**多组之间平台默认平均分配资金**
- 讲师强调新手必须理解"为什么上节课让关掉 neutralization 探测数据"（正负号会被调整）

## 4. 分组 Grouping（中性化的自然延伸）

- 分组不止做中性化：可分组 rank / 组均值 / 组 z-score / 组最小值
- **为什么要分组**：好坏是相对的——"负债多"单独看不是好信号，但在 AI 行业内比较时负债多 = 能借到钱 = 资本看好（选错比较对象 = 把大学生和一年级比四则运算）；正确分组后表现大概率变好
- 平台分组数据（grouping data，type=GROUP）：存每只股票的组别标签（如 H=层次聚类，有论文支撑）；创意分组例子：供应链上下游分组、负债分组——**做一个好分组本身也是数据来源/alpha 思路**
- **自定义分组 = bucket 算子**：参数 = 起点/终点/步长（如 0.1~1 每 0.1 一组）；常配 rank（先缩放 0-1 保证 cap 最大股 = 1）→ rank(bucket(x)) 按市值/流动性分组
- 实战例子：负债/equity = 股东杠杆（股东投 1 块借 2 块 → 杠杆 2 倍），按杠杆倍数分组 → 在自定义组内做中性化
- **用平台分组数据字段前加 densify**（压缩离散组号如 100101102 → 1,2,3…连续，计算快、防报错）

## 5. 好 alpha 三要素回顾（前三课总结，官方方法论）

1. **solid idea**（靠谱的想法，不是 unique idea；来源：论文/研报/AI/论坛）
2. **了解数据 + 了解 operator**，把想法"翻译"成表达式（unique implementation——同一想法多种写法）
3. **增强**：选更好分组、分组算子让其在合适人群内比较

## 6. 模板抽象化（本课进阶：替换的不只是字段）

- 上一课模板 = 替换数据字段；本课：**模板可抽象替换算子/分组/window** → 跨数据集迁移（基本面模板 → 期权数据）
- 但**禁止暴力遍历**所有 group/ts 算子组合（= 暴力搜索）；要聪明选择 → 用 AI
- AI 用法示范：给 AI 模板框架 + 全部可用 operator + 数据集字段信息 → 让它推荐填法（可要求中文回答）
- 美妙案例：group_rank 的第二参数不写 industry，**改用自定义动态分组：按过去 120 天历史波动率分组**（稳定值适合分组，20 天太短——"一年升一级，不隔两天换班"）
- 用 AI 前自己先定性定量了解数据（否则无法判断 AI 输出是否靠谱/过拟合）
- **中文论坛搜索技巧**：语言必须选"简体中文"——搜"模板"英文只出心灵鸡汤，中文全是实战技巧（讲师的黑色幽默实证）；搜"代码"找批量展开脚本；**警告：论坛模板有严重过拟合风险，不思考直接抄 → "每天只能拿一美元"**
- 展开模板时也要理解参数（不无脑全字段回测，如期权选短窗口 10-20 天而非 150 天）
