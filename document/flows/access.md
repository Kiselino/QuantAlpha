# 权限差距：用户 vs 顾问（access）

> 读取时机：**决定可用功能时**（生成/提交前、`qa status` 输出阶段后）。
> 权威决策规则：**agent 以 `qa status` 资格输出为准，不写死双分支**。
> 顾问路径细节来源：官方帖子（2026-09 已核实：28584425090455 顾问申请流程、
> 40902865718167 面试安排与违规说明、41473493185175 学习指南）。

## 1. 能力矩阵（用户 vs 顾问）

| 能力 | 用户 | 顾问 | 说明 |
|---|---|---|---|
| 可用区域 | USA | 12 区域 | `qa update-knowledge --regions ...` 按账户抓取 |
| 字段库 | 账户抓取范围 | 扩大 | validate 白名单读按账户抓取的 fields.json，天然自适应 |
| 表达式语言 | FASTEXPR | +PYTHON/ML | MVP 不做 PYTHON；当前 validate 对非 FASTEXPR 拒绝 |
| D0 模式 | 5000 分解锁（SILVER/GOLD） | 可用 | `d0_available = is_consultant or level in ("SILVER","GOLD")` |
| 提交门槛 | D1 | D0 | D0 门槛：Fitness≥1.3 / Sharpe>2.0 |
| 模拟 delay | 1 | 0 | 候选 settings 可指定 delay |
| 计分封顶 | 每天 1-2 个成功即可 | 提交 3+ 当天奖励封顶 | 相对分，美东 3AM 结算 |
| 并发 | 3（`--concurrency` 可调） | 待实测 | 顾问后实测 x-ratelimit-limit-minute 确认有无红利 |

## 2. 等级体系（与顾问资格正交）

| 等级 | 分数段位 | 说明 |
|---|---|---|
| BRONZE | > 1000 分 | 分数段位，**非顾问资格** |
| SILVER | > 5000 分 | 解锁 D0 模式（官方文章 38301762395415："To get access to D0 Alphas, you must reach 5,000 Individual Qualifier Score"） |
| GOLD | > 10000 分 | **GOLD 用户还不是顾问**（官方文章 8361844494359：10000 分仅是邀请资格之一） |
| 顾问 | 10000 分 + Gold + 完整申请流程 | 见下方顾问路径 |

- `is_consultant = consultant is not None or geniusLevel is not None`——与 level 正交
- 判定代码在 `qa/stage.py`；`qa status` 输出"等级"与"资格"两个独立字段

## 3. 顾问路径（官方帖子已核实，2026-09）

```
第一步：达到 10K → 进入 Challenge - Mainland China 排行榜
        排行榜规则：过去 60 天内有 Alpha 提交记录的 Gold 用户，
        按 IS Score / Uniqueness Score / 持续提交天数综合排名，每日更新
        → 邀请排行榜前列用户进入下一阶段
第二步：完成研究能力测试笔试（通常次日返回笔试结果）
第三步：笔试通过后，预约 5 分钟面谈（身份核实 + BRAIN 平台基础知识）
第四步：面试通过 → 从排行榜移除 → 8 月以后新用户隔天收到顾问申请邀请
        → 完成 Workday 顾问申请表（背调授权书/身份证件/背景调查问卷）
第五步：背景调查（vender eeVoices 联系确认身份）→ 签署咨询协议（第 1/19 页签字）
        → 收到填写银行卡通知 → 填写银行账户（中国大陆银行，人民币付款）
        → 成为 Full Consultant
```

**准入限制**（社区科普 28643095649943）：当前在金融机构或金融科技公司任职者，
可能因利益冲突**无法成为兼职顾问**。

**Workday 填写要点**（官方帖子）：全英文填写（除中文名）；First name=名拼音、
Last name=姓拼音、Chinese Name=中文全名；地址历史完整覆盖 5 年；
在职者不填离职日期；国籍填 CHINA；问卷 C-G 部分无特殊情况填 NO。

## 4. 风控须知（官方帖子已核实，2026-09）

- **面试安排**：平台发面试邀请邮件 → 截止日前完成预约 → 按时参加 →
  预约截止后一周内通知结果
- **两次面试机会**：预约后未参加 与 面试未通过 各算一次失败；
  未通过/未预约/未参加 → 账户可能被临时锁定；锁定后可通过再次面试申请解锁
- **账户锁定但没收到邮件**：发邮件至 `mainlandchina@worldquantbrain.com`，
  标题"【账户解锁】- 请求面试链接"
- **面试要求**：准备身份证件；Zoom 会议按"预约时间 + 本人姓名"填写；
  先在等候室等待
- **平台价值观**：重视真实、独立、可持续的研究能力；打击代打/代练/出租账号/
  代做研究/冒用身份/传播面试材料/黑灰产（详见 `document/reference/rules.md` 行为准则）

## 5. 决策规则

1. 任何涉及"顾问才能用"的功能，先看 `qa status` 的资格输出
2. 等级变化（BRONZE/SILVER/GOLD）**不触发**知识库刷新提示——只有资格变化才需要
   `qa update-knowledge --force`
3. 顾问后并发/字段/语言的实测差异：更新到本矩阵，不要写死到代码/生成指南
