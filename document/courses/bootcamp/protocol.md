# Bootcamp 执行协议（agent 专用）

> 本文件定义 RLHF 式学习闭环的全部规则。**每次会话开始按 README 顺序读到本文件后照此执行。**
> **运行方式**：本目录为公开协议与模板（随仓库分发）。个人执行副本建在本地 gitignored 目录
> `docs/bootcamp/`——把 protocol/rubric/plan-*/mastery.template 复制过去后初始化
> `mastery.json`（从 mastery.template.json 复制），摸底卷/错题本/答题记录等个人档案只留在本地。
> 文中 `mastery.json`/`private/`/`mock_exam/` 路径均指本地副本内相对路径；教材 `document/courses/` 为仓库公开路径。
> 核心目标：让使用者能**用自己的话、按官方口径**解释四大模块知识——笔试与面试考察的是真理解，不是背诵。

## 0. 会话起始

1. 读 `mastery.json` 确认当前状态；读当日计划（plan-1wk/plan-2wk 中带日期与进度的实际议程）
2. 若上次会话中断：先报告"上次进行到哪、剩余未完成项"，从断点继续
3. 开场向用户报告：今日议程 + 预计时长 + 当前最弱 3 考点（来自档案）

## 1. 每日闭环五步

```
① 开场诊断（~15min）
   规则：昨日错题必重考（出变体：换数字/换场景/换角度，不原题重考）；
        next_review ≤ 今天 的考点抽 2-3 个快速口答（每题 1 分钟内）；
        诊断结果并入 ③ 的出题池。
② 精学（60-90min；2 周版可减半）
    规则：从 document/courses/ 取当日教材 → 按"讲为什么"精讲：
        - **主线 = 官方《学习指南》四方向 + 四节新手课**（courses/official_quiz-guide.md）
        - 粒度纪律（防过拟合）：只学到"概念+机制"层——能用自己的话解释
          "是什么/为什么"即可；官方口径未明示的边角细节（次数/具体数值类）
          属答疑补充，**只作延展阅读，不设考题、不追问**；少即是多
        - 先讲概念为什么存在/解决什么问题
        - 关键机制逐步推导（公式、流程）
        - 用课程笔记中的讲师比喻/案例帮助记忆
        - 讲完一节 → 让用户用自己的话复述（费曼）；
          复述不清 = 没懂 → 回讲该节，不赶进度
③ 自测（45-60min）
    规则：出题 5-8 道（1 周版）/ 3-5 道（2 周版），配比按 rubric；
    **出题范围 = core 考点**（mastery.json level 默认 core / ext 两类）：
        - core：官方指南四方向点名的概念与机制 → 唯一出题来源
        - ext（延展）：顾问结算/竞赛/背调等用户阶段低频操作细节
          （income-*、iqc、genius、background）→ 讲课口头带过，**不设考题、不追问**；
          用户主动问才展开讲
    抽题权重：学习中考点 50% / 到期复习 30% / 新考点 20%；错题变体优先；
    **逐题交互：一次只抛 1 题 → 用户作答 → 点评完毕 → 再出下一题**（不一次性抛全部题，不一次性全判）；
    用户答"不会"计 0 分，不追问、直接讲该题要点。
④ 评分反馈（30min）
   每题按 rubric 打分 → 错因归类（概念混淆/记忆缺失/计算错误/表达不清）
   → 给出标准答案要点（注明官方口径出处）→ 给记忆锚点（比喻/口诀/关联）
   → 汇总：本日得分率、薄弱考点清单。
⑤ 档案更新（10min，必须完成——中断前也先做这步）
   更新 mastery.json：每题命中→wrong_count/status/confidence/last_review/next_review；
   写 private/错题本（追加今日错题：题目+你的答案+标准要点+错因）；
   写当日 plan 议程完成状态 + 明日议程。
```

## 2. 状态机与调度（mastery.json）

- status：未学 → 学习中 → 达标 → 熟练
- 升级：单题 ≥8 且连续 2 次 → 达标；≥9 且 3 次 → 熟练；单题 <6 → 保持/回到学习中
- confidence：0-1，按近 3 次得分滑动更新（0.3·本次分/10 + 0.7·旧值）
- next_review：错题=明天；达标后=+2 天；熟练后=+4 天抽查
- 摸底生成基线：≥8 分考点直接"达标"（confidence 0.8）；4-7 分"学习中"；<4 分"未学"

## 3. 摸底诊断（新人 D1 或速考 D1 定位基线）

1. 从 mastery.template.json 全考点按模块分层抽样：每模块 5-7 题（A 概念为主 + C 辨析），共 20-25 题
2. 用户可对不会的题直接说"不会"（不计重罚，计 0 分）
3. 判分后生成 mastery.json 基线 + 输出诊断报告：
   - 每模块得分率 + 建议投入天数（<40% → 2.5 天；40-70% → 2 天；>70% → 1 天压缩）
   - 模块学习顺序建议（最弱优先还是先易后难由用户偏好定）
4. 摸底卷与结果存 `private/diagnosis-<日期>.md`；结果只存本地

## 4. 题型（详见 rubric.md）

A 概念解释（40%）/ B 机制计算（20%）/ C 概念辨析（20%）/ D 场景判断（20%）

## 5. 模拟评测（D6/D7 速考；2 周版 D14 后按需）

- 模拟笔试：90 分钟闭卷 ~20 题（A×8/B×4/C×4/D×4）；当场计时作答；判分 + 诊断报告 + 薄弱清单
- 模拟面试：30 分钟口答情境——开场自我介绍 → M1 随机问 → 按 mastery 弱项追问（模拟面试官"再讲讲/为什么"式追问）→ "讲一个你提交过的 alpha"（用 qa.db 真实记录；讲 hypothesis/结构/为什么有效/失败）→ 收尾
- 面试评分：概念准确 / 用自己的话 / 追问抗压 / 真实性

## 6. 出题与合规红线（不可违背）

- 题目只从 `document/courses/` 官方材料 + mastery 考点产生；**严禁收集/引用面经、真题、题库**
- 无官方口径的题目须标注"讲师/课程口径"及日期（如 4 月答疑 vs 6 月官方说明冲突时以官方最新为准并提示）
- 用户答题内容留在本目录（个人），不进 document/、不进 git 提交
- 每个学习日结束输出一行进度（考点达标数/总 60 + 明日聚焦）
