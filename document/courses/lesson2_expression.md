## 要点摘录（按备考价值抽取）

### Alpha 构成与平台导航（M2）
- Alpha = operator（运算符）与 data（数据字段）的组合
- 查找路径：平台菜单 Data（数据集/字段搜索 + dataset id）；编辑器 LN 选项卡 → Operator（全部运算符列表）
- AI 生成报错 Unknown Variable 的根源：AI 不熟悉平台字段命名 → 回 Data 页核实替换
- 平台不支持的算子可用近似替代实现想法（讲师："没有某算子不是放弃想法的借口"）

### 数据定性认知（M3）
- 两大常见类别：fundamental（基本面：财报指标，季度/年度更新 → 低换手 alpha 特征）vs price volume（量价：每日更新 → 高换手策略）
- 定性了解路径：Data 页 → 数据集 → 描述 → 字段含义（可用 AI 辅助理解术语）

### 数据定量探测（M3，对应"Six Ways to Quickly Evaluate a New Data Set"）
- 方法：neutralization=None + decay=0 + 关 null handling → 只回测单一数据字段 → 看 long count / short count
- 判断逻辑：全为多 → 字段基本全正；全为空 → 全负；再用阈值（>0.25/>0.5）统计年股票数确定值域（如 0~1 比率型、从不等于 0 且小于 1）
- 目的：形成数据分布直觉（正负性/区间/更新频率），为构造 alpha 提供思路

### 算子讲解（M3/M2）
- **rank**：横截面排序映射到 0-1 均匀分布；对极端值不敏感（抗离群），但压缩差异
- **ts_delta(x,d)**：时间序列差值（环比/同比）；本质 = x - ts_delay(x,d)，可等价替换
- **trade_when**：三参数条件算子；优先判断退出条件 → 不成立再判断进场 → 否则维持原仓位；本质多个 if-else 嵌套，可用于择时调仓
- 分类：时间序列类 / 横截面类 / 多源逻辑类
- 用 AI 理解表达式：把全部 operator 列表 + 表达式给 AI 要通俗解释

### Alpha 模板（核心概念，与仓库 templates.md 机制一致）
- 枚举全部算子×字段组合不可行（指数爆炸）
- 模板 = 从有效 alpha 中抽出变量占位符（如某数据类别为变量）→ 限定搜索空间 → 批量替换同类别字段生成候选
- 落地方式：代码登录平台 → 获取数据集字段列表 → 循环生成表达式 + settings → 批量提交回测
- 类比：地质勘探先在"有矿的深度"打钻，再展开

### 作业（Day2，官方 Course2 作业对应）
1. 解释 long count 和 short count 的定义与平台计算方式
2. 基于 Six Ways 文章研究某字段（anl4_cff_flag）更新频率 + 现实生活类比
3. 数学上解释某算子（ts_std_dev）为何能测出更新频率
4. 代码批量生成表达式并回测（20+ 次）
5. 提取投资 idea 关键词 → 平台搜字段 → 结合算子列表让 AI 写表达式（3 个变体，展示思考证据）
