# 有效模版库（templates）

> 读取时机：**需要时查阅**；快速模式引擎 c 必读（`document/flows/generation.md` §1.3）。
> 更新规则：经验沉淀时总结（`document/flows/experience.md` §4 模版总结）、
> 调研时收集网络模版（`document/flows/update-knowledge.md` §4）。

## 合规边界（不可违背）

- 模版 = **脱敏结构模式**：算子组合骨架 + 适用场景 + 参数经验值
- **永不写真实 alpha 表达式/字段依赖/账号数据**（平台分享红线 + 个人信息约定）
- 字段一律用占位符（`x`/`y`）与字段族描述（"价格类""波动率类"），不写具体字段名
- 网络来源必须标注 URL 与可信度（官方/高赞社区/普通帖）

## 条目格式

```markdown
## T<n> <名称>
- **结构**：<算子组合骨架，字段用 x/y 占位>
- **适用**：<数据集类型/字段族/场景>
- **参数经验**：<decay/中性化/截断/窗口>
- **来源**：<自有沉淀 / 网络-URL / 官方文档>
- **实证**：<PASS 案例数 / 注意事项>
```

## T1 黄金组合（基本面主信号）

- **结构**：`group_rank(ts_rank(x, N), subindustry)`
- **适用**：基本面字段族（价值/质量/成长类）；多空方向由 x 取负控制
- **参数经验**：decay 0（基本面）；truncation 0.05-0.1；窗口 N 20-60
- **来源**：自有沉淀（2026-08 首轮 4 批 40 候选实证）
- **实证**：通过率最高的基础结构；行业分组优于 industry 分组（subindustry 分组保持）

## T2 价格快反转（辅信号常客）

- **结构**：`ts_rank(-ts_delta(x, N), M)`（x = 价格类字段，close 等）
- **适用**：价格/技术类字段族；作为主信号的辅信号（小权重 0.2-0.5）
- **参数经验**：N=5（快反转），M=20；配合主信号 decay 时效果更稳
- **来源**：自有沉淀（混合簇多次实证）
- **实证**：单独使用 Fitness 一般，但作为辅信号能显著提升混合 Fitness

## T3 波动率情绪信号（期权/波动类）

- **结构**：`ts_rank(ts_backfill(vol_x, N), M)`（vol_x = 波动率/期权情绪类字段）
- **适用**：期权 IV 类字段族（put/call 波动率）
- **参数经验**：decay 8（关键旋钮）；ts_backfill 补齐缺失；窗口 M=60
- **来源**：自有沉淀（期权簇 5-9 轮实证）
- **实证**：单 IV 信号 Fitness 卡 0.89 天花板；与 T2 混合突破到 1.18+（见 T4）
- **无效旋钮**：truncation 0.03-0.10 无差异；排名窗口 30/45/90 均劣于 60；TOP1000 小宇宙不适用

## T4 双独立信号源混合（突破 Fitness 天花板）

- **结构**：`主信号 + 0.3~0.5 * 辅信号`（主=基本面/预期类，辅=T2 价格反转或 T3 波动情绪）
- **适用**：单信号源卡 Fitness 时的突破路径；混合簇（基本面+价格 / 期权+价格）
- **参数经验**：辅信号权重 0.3-0.5 最优；两者相关度应低（独立信号源）
- **来源**：自有沉淀（2026-08-15/17/21 多次实证）
- **实证**：单 IV Fitness 0.89 → 加 0.5 权重价格反转 → Sharpe 1.87 / Fitness 1.18 直接 PASS；
  与"价格反转 × put IV 恐慌"混合簇一致——**期权情绪 × 价格是可靠组合配方**

## T5 三确认结构（主 + 双辅确认）

- **结构**：`基本面主信号 + IV/OI 辅信号(0.3 权重) + 反转辅信号(0.2 权重)`
- **适用**：追求更高 Fitness 的成熟主题（盈利/现金流/ROE 类主信号）
- **参数经验**：IV/OI 辅 decay 8；反转辅权重 0.2；窗口随主信号周期
- **来源**：自有沉淀（2026-08-24/25 三确认配方）
- **实证**：双确认(主+1辅) → 三确认(主+2辅) 是稳定的提升路径

## T6 分析师预期修正类

- **结构**：`ts_rank(ts_delta(est_x, N), M)` 或 `ts_rank(est_flag_x, N)`（est = 分析师预期类字段）
- **适用**：分析师/盈利预期字段族（预期修正、盈利惊喜）
- **参数经验**：decay 0-4；flag 类字段适合布尔确认（0/1 信号）
- **来源**：自有沉淀 + 官方学习材料
- **实证**：预期修正方向性明确；flag 组合（双 flag 反转）可作增强旋钮

## T7 设置三角调优（decay/truncation/neutralization）

- **结构**：`表达式不变，只调 settings`——decay 分级调优 + truncation 0.05-0.1 + neutralization 按分组
- **适用**：任何 Fitness 卡壳（0.7-1.0 区间）的 alpha，先调设置再改代码
- **参数经验**：decay 1-3 → TO 40-60%；4-7 → 25-40%；8-15 → 15-25%；15+ → <15%；
  反转类 decay 5-8、动量类 10+；原则 = 用能保持 TO<70% 的最小 decay，从低逐步加
- **来源**：网络-https://support.worldquantbrain.com/hc/en-us/community/posts/40205054470295（中可信度）
- **实证**：社区案例 decay 5→10 让 Fitness 0.70→1.02（零代码改动）；与自有期权簇 decay 8 经验一致

## T8 算子序列选择（时序/截面变换顺序）

- **结构**：A. `group_rank(ts_rank(x, N), group)`（时序→截面：去个股基线偏差）；B. `ts_rank(rank(x), N)`（截面→时序：衡量相对地位变化）
- **适用**：合成复合信号时选型；A 适合基本面/波动类（保留历史上下文），B 适合衡量相对排名改善
- **参数经验**：A 的 N 60-120（半年基准）；B 的 N 跟随信号周期
- **来源**：网络-https://support.worldquantbrain.com/hc/en-us/community/posts/42801563919895（中可信度）
- **实证**：序列顺序显著影响信号分布与风险参数，生成时必须有意识地选择（T1 黄金组合即 A 型）
